# Vejas777 Tactical Hub

Sukurk pilnai veikiančią, modernią ir profesionaliai atrodančią lietuvišką streamer'io svetainę „VEJAS777“.

SVETAINĖS TIKSLAS:
Tai yra asmeninė VEJAS777 streamer'io / content creator svetainė. Pagrindinis tikslas – aiškiai parodyti, kur žiūrėti tiesioginę transliaciją, rasti YouTube, TikTok, Kick, Discord ir paremti kūrėją.

DIZAINAS:

* Visa svetainė turi būti lietuvių kalba.
* Pagrindinė tematika: tamsi karinė / tactical / military estetika.
* Naudok MULTICAM / camouflage įkvėptą foną.
* Spalvos: labai tamsi žalia, juoda, olive, khaki ir subtilūs pilki atspalviai.
* Naudok raudoną spalvą tik svarbiems LIVE indikatoriams ir akcentams.
* Dizainas turi atrodyti moderniai, tvarkingai ir profesionaliai, o ne kaip senas gaming puslapis.
* Naudok subtilias animacijas, hover efektus ir lengvą glow efektą.
* Venk per didelio animacijų kiekio.
* Svetainė turi būti greita ir patogi.

RESPONSIVE:
Svetainė turi būti visiškai responsive.
Ji turi puikiai atrodyti:

1. telefone vertikaliai;
2. planšetėje;
3. kompiuteryje horizontaliai;
4. dideliame monitoriuje.

Mobile-first dizainas yra labai svarbus. Telefone visi pagrindiniai mygtukai turi būti patogūs paspausti pirštu.
